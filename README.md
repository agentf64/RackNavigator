# Fighting Pint - Navigator

Navigator is inspired by a common feature found in image-editing applications: the ability to use an overview or minimap to quickly navigate a much larger workspace.

I've used VCV Rack since version 1, and as the module library has grown, I haven't come across anything that provides quite the same type of navigation. Navigator was created to fill that gap.

My development skills are limited, and much of this module was created with the assistance of AI. Because of that, I chose to release Navigator under **CC0-1.0**, so other developers are free to use it, modify it, improve it, or take inspiration from it.

## How It Works

The default hotkey to open the minimap is:

**Alt + M** on Windows/Linux  
**Option + M** on macOS

You can configure your own hotkey or use either of the quick-set options:

- **M**
- **Middle mouse button**

Press the hotkey once to open the minimap.

**Left-click** a location on the minimap to immediately navigate to that area of your rack.

To close the minimap, you can:

- Press the hotkey again
- Press **Esc**
- Click anywhere outside the minimap

## Appearance

Navigator supports both **light and dark modes**.
